# Campus Hub repository guidance

Campus Hub uses React, Vite and TypeScript in `frontend/`, and Node.js,
Express and MVC layers in `backend/`. Keep frontend code, backend code,
backend tests, local development data and Supabase migrations inside their
respective application folder.

Do not introduce Next.js. Follow the architecture, security and validation
guidance in `skills.md`, `CONTRIBUTING.md` and `SECURITY.md`.
